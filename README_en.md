## Support platform
**Windows、Mac、Linux**
## Supported sign-in modes
- ✅ QR code sign-in (verified)
- ✅ GPS check-in (verified)
- ✅ GPS + photo check-in (verified)
- 🚧 Sign in with password

## Features
- ✅Supports scheduled check-in
- ✅ Support 24 hours unattended service
- ✅ Supports one-click installation of msi installation package
- ✅ Supports customizing latitude and longitude to complete location check-in
- ✅ Supports loop detection of GPS and QR code check-in tasks
- ✅ Supports automatic import of data.json configuration file
- ✅ Supports automatically saving information to data.json file
- ✅ Supports continuous check-in, no need to repeatedly capture cookie values
